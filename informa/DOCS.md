# InFormha

Dopo l'installazione:
1. Avvia l'App.
2. Abilita "Mostra nella barra laterale" se non già visibile.
3. Apri **InFormha** dalla sidebar di Home Assistant.
4. I dati vengono salvati nello storage persistente dell'App.

La guida esercizi sulla macchina reale verrà aggiunta dopo l'acquisizione delle foto.
