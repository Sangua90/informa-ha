## Publication gates and limits

Main is promoted only after the exact source commit passes GitHub Actions tests and actual Docker builds for amd64 and aarch64. Installing on Home Assistant requires first checking that no workout is open. A real provider preview can be checked without recording a fake workout or adding a proposal to history.

Tests above use disposable data or browser simulation. They are not a physical iPhone test, a completed real training session or a physiological guarantee. Coverage refers to the primary groups in the supported catalog. Skipped work, pain/exclusions, short time or an insufficient exercise count can leave coverage incomplete; the app must say so. The split starts with the next workout after migration, retaining old data for recovery, progression and weekly variants. Dumbbell kg increases require an already recorded compatible higher load; unknown discs or handle mass are never invented. Individual numeric Coach notes take precedence.
